# Getting help

- **How do I…?** Start with the [user guide](docs/user-guide/USER_GUIDE.md), the [desktop guide](docs/user-guide/DESKTOP.md) and the [CLI reference](docs/user-guide/CLI_REFERENCE.md). Run `evyro doctor` to check your install.
- **Something is broken.** Open a [bug report](https://github.com/AINomadDev/evyro/issues/new?template=bug_report.md). Run `evyro bug-report` and attach its redacted output.
- **I have an idea.** Open a [feature request](https://github.com/AINomadDev/evyro/issues/new?template=feature_request.md).
- **A security problem.** Do not open a public issue. See [SECURITY.md](SECURITY.md).
- **Want to contribute?** See [CONTRIBUTING.md](CONTRIBUTING.md).
